# حملة يلا نصلي - BAGHDAD

موقع تفاعلي لتركيب الصور الشخصية داخل إطار حملة **يلا نصلي** ونشرها عبر **GitHub Pages**.

## طريقة النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `yalla-nusalli`).
2. ارفع الملفات التالية إلى المستودع:
   - `index.html`
   - `style.css`
   - `script.js`
   - مجلد `assets/` وبداخله `frame.png` و `logo.png`
3. من تبويب **Settings > Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
